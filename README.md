# Trail log app
## About
- これは登山記録をつけるためのアプリです
- MySQLでデータベース(DB)を設計します
- Goを用いてDBとの接続，HTMLのレンダリング，データの登録・取得を行います
- DBを用いたアプリケーションの勉強と趣味の登山を楽しむ目的を兼ねて作成します
- まだ初期段階なので機能は限定的です
- DBの設計方針や詳細は以下の通りです
    - 属性は「登山した日付(date)」，「山名(mountain_name)」，「天気(weather)」，「行動時間(duration)」，「その他メモ(memo)」です
    - 主キーはdateです
    - このDBは第3正規系を満たしますが，「標高(elevation)」を追加する場合，山名が決まれば標高も決まり，推移的関数従属性が生じるため第3正規系を満たさなくなります（この場合は山のテーブルを別途用意すべきでしょう）

## How to run this app?
- 以下のコマンドを実行するとアプリが起動し，URLが表示されるのでそれをブラウザに貼り付けることで使用できます
`DB_PASSWORD=pass go run main.go`（ただし，`pass`は各自のMySQLのパスワードに置き換えてください）
